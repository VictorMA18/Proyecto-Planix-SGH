# Glosario

- **Organización (Tenant):** entidad empresarial independiente dentro de la plataforma.
- **Jornada de asistencia:** registro diario (`JornadaAsistencia`) de un usuario, que agrupa uno o varios movimientos de entrada/salida (`MovimientoAsistencia`) ocurridos ese día.
- **Ciclo de asistencia:** par entrada-salida (`MovimientoAsistencia` tipo `ENTRADA` seguido de `SALIDA`) dentro de una jornada. Una jornada puede tener uno o varios ciclos.
- **Fan-out:** creación de una fila por destinatario a partir de un único evento, sin duplicar el contenido del evento.
- **PWA:** Progressive Web App, build web instalable de Expo.
- **RBAC:** control de acceso basado en roles, evaluado por membresía a organización.
